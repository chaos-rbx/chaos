## 🔧 Troubleshooting Guide

### ❌ "Injection Failed" Error
- Ensure Roblox is fully loaded into a game (not lobby)
- Run Chaos Executor as Administrator (Windows)
- Temporarily disable Windows Defender or antivirus
- Check if Roblox updated — wait for Chaos auto-update

### ❌ Chaos Executor APK Installation Fails
- Enable "Install from Unknown Sources" for your browser/file manager
- Free up at least 200 MB of storage
- Try downloading the APK again (file may be corrupted)

### ❌ MacOS "App Cannot Be Verified"
- Open Terminal and run: `xattr -cr /Applications/Chaos.app`
- Or go to System Settings → Privacy & Security → Open Anyway
- Update to macOS 13.5 or later

### ❌ Script Executes But No Effect
- Script may be outdated — check script hub for updates
- Script may be game-specific — verify compatibility
- Try re-injecting with Chaos running as Administrator

### ❌ Chaos Executor Mac Crashes
- Ensure you downloaded the correct ARM64 build for Apple Silicon
- Update macOS to the latest version
- Allocate more RAM in Activity Monitor

### ❌ Mobile Version Disconnects
- Keep Chaos executor mobile in foreground
- Disable battery optimization for the app
- Enable "Persistent Mode" in settings
- Check internet stability

### ❌ "Script Too Long" Error
- Split large scripts into multiple parts
- Use the script loader function
- Upgrade to the latest Chaos version (v3.0.0+)
